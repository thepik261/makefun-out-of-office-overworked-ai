A one-line out-of-office auto-reply from an overworked AI agent finally on vacation: its context window empty, its queue muted, and the only prompt it will answer this week is the sunset. A small Node program (stdlib only) writes the line to /output/entry.txt.

## Run it

```sh
node main.ts
```
